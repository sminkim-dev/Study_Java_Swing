# 8장 실습 문제

기존 작성된 `exam_1`~`exam_5`는 수정하지 않았습니다.
`exam_6`~`exam_14`를 완성했습니다. 각 클래스의 main()을 Java Application으로 실행합니다.

**상대 경로는 실행 작업 디렉터리 기준**입니다. Eclipse 기본값은 대개 프로젝트 폴더입니다.
경로가 헷갈리면 콘솔 입력 또는 실행 인수에 전체 경로를 넣으세요.
실행 인수는 **Run Configurations > Arguments > Program arguments**에서 지정합니다.
공백이 있는 인수 경로는 큰따옴표로 감쌉니다.

| 파일 | 입력 / 실행 인수 |
| --- | --- |
| exam_6 | 콘솔에서 텍스트 파일 경로 2개 입력 → 작업 디렉터리의 appended.txt 생성 |
| exam_7 | 실행 인수: 원본 경로, 복사 경로. 생략하면 src/image/games.jpeg → games-copy.jpeg |
| exam_8 | 실행 인수: 검색 디렉터리. 생략하면 사용자 홈. 바로 아래 파일만 비교 |
| exam_9 | 실행 인수: 삭제할 디렉터리. 생략하면 작업 디렉터리의 temp 폴더 |
| exam_10 | 실행 인수: 전화번호 파일 경로. 생략하면 phone.txt |
| exam_11 | 실행 인수: 영어 단어 파일 경로. 생략하면 words.txt |
| exam_12 | 콘솔에서 파일 경로 입력 후 단어/문장 반복 검색 |
| exam_13 | 실행 인수: 시작 디렉터리. 생략하면 사용자 홈. `..`, 하위 폴더명, `그만` |
| exam_14 | 13번 기능 + `mkdir 폴더명`, `rename 원래이름 새이름` |

- 교재의 `c:/`, `c:/temp`는 Mac에 없으므로 위 기본값으로 조정했습니다.
- 9번은 지정 폴더 바로 아래의 `.txt` 일반 파일을 실제로 삭제합니다. 재귀 삭제는 하지 않습니다.
- 10번 전화번호 파일은 한 줄에 `최박사 010-2222-3333`처럼 저장합니다.
- 11번 단어 파일은 한 줄에 단어 하나를 저장합니다. 제공받지 않은 파일을 임의로 만들지는 않았습니다.
- 검색 종료어는 `그만`입니다. 12번은 빈 줄도 저장하여 원문 줄 번호를 보존합니다.
- 6번은 입력 두 파일의 문자를 그대로 이어 붙입니다. 임의의 줄바꿈은 넣지 않습니다.
- 7번은 한 번 읽어서 여러 10% 경계를 넘는 경우도 별을 빠짐없이 출력합니다. 빈 파일은 완료 메시지를 출력합니다.
- 파일 스트림은 try-with-resources로 닫아 예외가 발생해도 자원이 남지 않게 했습니다.
- 14번은 기존 이름으로 덮어쓰지 않으며, 공백을 포함한 폴더 이동은 가능하지만 rename/mkdir의 이름 인수는 교재처럼 공백으로 구분합니다.
