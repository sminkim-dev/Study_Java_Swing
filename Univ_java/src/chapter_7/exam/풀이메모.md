# 7장 실습 문제

Eclipse에서 해당 `exam_번호.java`를 선택하고 **Run As > Java Application**으로 실행합니다.
파일 이름과 공개 클래스 이름을 기존 프로젝트의 `exam_번호` 형식에 맞췄습니다.
입력 예시와 조건은 제공된 PDF 원문을 기준으로 했습니다.

| 파일 | 내용 |
| --- | --- |
| exam_1 | Vector에 양의 정수 저장, -1로 종료, 최솟값 |
| exam_2 | read / changeToZero / showAll / add 메서드, 0으로 입력 종료 |
| exam_3 | 주식 종목 등록 후 주가 검색 |
| exam_4 / exam_4_2 | 4-(1) HashMap / 4-(2) 두 ArrayList로 쇼핑 비용 계산 |
| exam_5 | 고객 마일리지 누적 및 최댓값 |
| exam_6 | 입금·출금·조회·전체조회 |
| exam_7 / exam_7_2 | 7-(1) HashMap / 7-(2) ArrayList로 도시 4개 관리 |
| exam_8 / exam_8_2 | 8-(1) Vector / 8-(2) HashMap으로 학생 4명과 장학생 관리 |
| exam_9 | Vector<Shape>와 상속으로 콘솔 그래픽 편집기 |
| exam_10 | 이중 while로 중복 단어 제거, 첫 등장 순서 유지 |
| exam_11 | 이름별 걸음수 누적·합계·정수 평균 |
| exam_12 | mov / add / sub / jn0 / prt / exi 가상 기계 |

- 도시 입력 순서는 원문 실행 예시에 따라 `도시, 경도, 위도`입니다. 숫자는 예시 그대로 저장합니다.
- 학생은 `이름, 전공, 학번, 학점` 순서로 입력합니다. 4.0 이상을 장학생으로 출력합니다.
- 맵은 이름으로 빠르게 찾기 위해, 리스트/벡터는 저장 순서와 인덱스 접근을 연습하기 위해 사용했습니다.
- 9번 삭제 위치는 0부터 시작합니다.
- 10번은 삭제 후 원소가 앞으로 당겨지므로 삭제한 인덱스를 다시 검사합니다.
- 12번의 `jn0`는 알파벳 o가 아닌 숫자 0입니다. 점프 주소는 0부터 시작합니다.
  `go`로 입력 프로그램을 실행하고 다음 프로그램을 새로 받습니다. `그만` 또는 입력 종료로 끝납니다.
  미초기화 변수, 잘못된 점프, 정수 범위 초과를 검사하며 100만 명령 이상 실행 시 무한 반복 방지를 위해 중단합니다.
